# 06 页面清单

整理日期：2026-09-30；2026-10-04 按 `spec-redesign-changes.md` 与 v33 定稿同步。本章只写入口、区块、按钮、弹层、落点、空状态、接口和订阅；业务规则以 03 章为准，视觉按 02 章，接口 / actions / 推送按 05 章。旧画稿和交接记录的作废要求不再执行。页面文案集中放进 `shared/copy`。

## 1. 约定

- 按钮只看后端 `actions`（00 章第 1 节、05 章第 1.5 节）。本文写「按钮 Y（`X`）」表示 `actions` 里有 `X` 时显示 Y：`enabled: false` 时显示禁用，下方写 `disabledReason`；点了以后要不要原因框看 `reasonRequired`。`lockedReason` 有值时在状态区显示。页面本地条件（没勾选、购物车为空）才由前端禁用。
- 金额、上限、库存只显示后端返回的 `xxxCents`、`maxQty`、`stockQty` 等；表单里的行金额、合计、差异是输入预览（00 章第 1 节）。
- 能进哪些模块、「我的」有哪些入口、登录落点，按当前账号的 `modules`、`menus`、`landing`（05 章第 2 节）。
- 层级：一级页面没有返回，底部标签用 `wx.reLaunch` 切换；二级页面左上角返回，回到上一页并恢复筛选和滚动位置。管理员和多模块员工的模块首页是二级。
- 加载、空、断网、报错、无权限、找不到、状态过期、放弃修改、提交中、实时提示都按 02 章第 5 节，本文每页只写本页的空状态文案和报错文案。总表「表单」列标了的页面有放弃修改确认。
- 推送主题和权限见 05 章第 12.2 节，收到变更后的界面处理见 02 章第 5.4 节。各页「订阅」只列主题。
- 状态码见 04 章，页面上用 `shared` 状态表里的中文名。

### 1.1 公共区块

外观见 02 章第 4 / 6～8 节。本文所有字段、日期、金额、单号、联系电话与登录手机号均写字段名；字段名在左、值在右，可两列并排，备注 / 对账期间 / 完整时间占整行。小字多个字段用两个全角空格，不用「 · 」拼接。

| 区块 | 内容 | 组件 |
|---|---|---|

| 底部操作区 | 最多 2 个按钮，次左主右，无更多；第三项按各页放页面最下面灰字，剩下 1～2 项时作废 / 取消也进底栏 | `hz-action-bar` |
| 明细 | 一张表格，首列标题「产品明细 / 花材明细」，后面数量、单位、单价、小计；名称下面编码，内部不放产品图。底部「合计数量 / 合计金额」一行两列，单行也显示。发货表只数量 / 实发 / 单位；收货数量写实收，编码行写采购数量 | `hz-line-item` |
| 编辑明细 | 点行弹居中小窗口：数量步进器 + 单位、单价框后缀元、小计、删除 / 确定；添加产品 / 花材选好后进入同一窗口，不能删的流程不显示删除 | 明细编辑窗口、`hz-stepper` |
| 变更 / 改价 / 退货记录 | 每条动作与操作人、完整修改时间、旧 → 新、原因；数量带单位；变更记录无数据写没有修改 | `hz-records` |

| 模块首页 | 待办并排小卡（大数字，0 也显示可点）→ 常用大窗格 → 可选资料小格；不写今日数字和身份行 | `hz-module-home` |
| 搜索 / 筛选 | 搜索独占整行；状态行最右筛选文字 + 小图标无框，非默认条件变红带个数；日期完整年月日，等待标签带数；结束类状态和对象收进筛选弹层 | `hz-search`、`hz-filter-bar` |
| 进度条 | 订单 3 格、售后 3 格、采购 2 格、邀请 2 格；已发生日期完整年月日，缺失确认日期留空；取消 / 拒收 / 关闭替换末格，作废追加灰格。收付款、对账单、手工出入库、报损、盘点不加 | 公共进度组件 |

### 1.2 列表级按钮

列表级按钮从列表接口顶层 `actions` 返回，写法同第 1 节；新建订单、采购单、售后、档案等使用其动作码。门店售后列表没有申请按钮，申请只从已发货订单详情进入。批量确认订单和批量发货由列表级动作与每张候选单据的动作共同控制可选性，版本、状态变化返回逐单结果。

### 1.3 弹层和整页（2026-10-04 定稿）

内容有记录列表、能跳到其他单据或复杂表单时使用整页：订单确认 X4、售后详情 S10 / X6、采购详情 P7 / C4 / W3、门店资料 X12、目录产品 X13、选择产品 X14、选择订单 X15、填报详情 C9、供应商资料 C10、收付款详情 F12、对账单表单 / 详情 / 图片 F13～F15、往来设置 F16。

短只读、单层表单、筛选与选择保留半屏：日志、员工 / 客户 / 花材资料、管理分类、需求来源、退货、改价、原因、多收 / 多付退回、批量确认订单选日期、已选产品。编辑明细用居中小窗口；一句确认用居中确认框。弹层最多再切一层，跳页面先关弹层；返回时不重开。F10 / F11 财务单据页删除，财务来源只读复用原单据模板。

## 3. 主包

### M1 登录

- 入口：没有绑定账号时打开任何页面；退出登录后。
- 区块：品牌背景整屏（`hz-cover` `full`，下部渐亮到墙色）→ 上部 logo → 下部隐私协议勾选（「我已阅读并同意《花众小程序隐私保护指引》」，点书名号部分打开微信隐私保护指引）→「手机号快速验证登录」→ 按钮下一行 12px 次要色提示「请用在花众登记的手机号」（2026-10-03 改版）。检查登录状态超过 `SKELETON_DELAY_MS` 时 logo 下面写一行「加载中」。没勾选时点按钮的表现见 03 章第 8.5 节，提示写在按钮上方的 `hz-error`。
- 小程序启动先进本页：已绑定就按 `landing` 直接 `reLaunch`，不显示登录区；账号停用显示 02 章第 5.3 节的停用状态（「退出登录」调解绑，之后回到登录区）。
- 落点：按 `landing`。从分享卡片进来的，登录后回 M2 继续。
- 报错：按 05 章 `POST /auth/bind-phone` 返回的 `message`；用户在微信授权框里点了拒绝，不报错，留在本页。
- 接口：手机号登录绑定、当前账号。

### M2 链接落地

- 入口：邀请分享卡片。门店 / 供应商未登录落地均为整页窗光、字标、「邀请你在线订货 / 邀请你填报」、往来方名称，底部隐私勾选、手机号快速验证登录、提示「请用在花众登记的手机号」。
- 门店邀请按 `GET /store-invites/:token` 判断：绑定 self 直接 reLaunch S1；邀请失效显示失效；绑定 other 提示当前账号并提供去我的；未绑定就在本页验证登录，成功直达 S1。供应商邀请解析后，已登录且有权直接进 P4；未登录验证成功后解析原邀请进 P4，不丢失目标。
- 失效按 02 章统一状态，原因取后端；接口：解析分享链接、手机号绑定。

### M3 花众首页

- 区块：花众字标 → 身份行（岗位 · 名字，右边日期）→ 两列入口卡（图标、模块名、箭头，按 `modules`；个数为单数时最后一张占整行）。不显示待办。
- 接口：当前账号。
