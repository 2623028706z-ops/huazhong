## 技术栈一句话

原生微信小程序 + TypeScript + WXML + 纯 WXSS + TDesign（外包花众组件）；后端 NestJS 跑在微信云托管；数据库 PostgreSQL，数据层 Drizzle，校验 Zod（枚举和字段规则在 `shared` 定义一次）；实时同步 WebSocket + LISTEN/NOTIFY；后台任务 pg-boss。
