# 02 前端与视觉

整理日期：2026-09-30。视觉取值来自冻结原型（路径见 README），本章是唯一出处，写代码以本章为准。品牌主色、字体、圆角不改，要改先确认。只做手机。

## 1. 原则

- 全站一套样子：同一种东西（按钮、卡片、状态标签、提示、空状态、加载、报错）只有一种写法，只在 `hz-*` 组件里定义一次。
- 页面不写外观，只写布局。页面的 WXSS 只允许间距、排列、显示隐藏。
- 设计值只从 `styles/tokens.wxss` 读，不写死颜色、字号、圆角。Stylelint 检查。
- 所有状态（加载、空、断网、出错、提交中、不可操作、过期）都有统一的组件和文案，页面不自己拼。

## 2. 设计变量（`styles/tokens.wxss`）

```css
page {
  /* 颜色 */
  --hz-brand: #934832;   /* 主按钮、导航选中、图标、链接、待付金额 */
  --hz-ink: #2f2622;     /* 正文 */
  --hz-muted: #766a60;   /* 次要文字，对比度 ≥ 4.5:1 */
  --hz-paper: #f6f1ea;   /* 顶栏、底栏、首页底色 */
  --hz-bg: #f5f1eb;      /* 页面底色、对账格 */
  --hz-hair: #e4dacd;    /* 描边、分隔线、禁用按钮底色 */
  --hz-line: #ece4da;    /* 列表行分隔线 */
  --hz-tint: #ecdcd1;    /* 头像、购物车图标底色 */
  --hz-green: #5d7a5f;   /* 完成状态、入库数量 */
  --hz-amber: #a4692a;   /* 等待状态、改价标记 */
  --hz-danger: #a83f36;  /* 表单错误、出库数量、退出登录 */
  --hz-danger-bg: #f8e9e6;
  --hz-notice-bg: #f7ebe0;
  --hz-notice-ink: #8a4f2c;
  /* 字体 */
  --hz-serif: "HZ Serif", "Songti SC", serif;  /* 思源宋体子集 */
  --hz-font: 14px;
  --hz-font-sm: 12px;
  --hz-font-xs: 11px;
  --hz-font-title: 17px;
  /* 尺寸 */
  --hz-radius: 2px;
  --hz-radius-sheet: 14px;
  --hz-tap: 44px;
  --hz-nav: 44px;
  --hz-tabbar: 62px;
  --hz-input: 42px;
  --hz-textarea: 72px;
  /* 间距 */
  --hz-gap-page: 12px;    /* 卡片左右 */
  --hz-gap-home: 20px;    /* 花众首页、模块首页 */
  --hz-gap-bar: 14px;     /* 顶栏、搜索栏、底栏 */
  --hz-gap-sheet: 16px;   /* 弹层内容 */
  --hz-card-pad: 16px;
  --hz-card-gap: 10px;
  --hz-row-pad: 12px;
  --hz-line-gap: 6px;     /* 卡片内三行之间 */
  /* TDesign 主题：只改变量，不覆盖内部样式。变量名已按 1.17.0 核对 */
  --td-brand-color: var(--hz-brand);
  --td-radius-default: var(--hz-radius);
}
```

状态颜色三类，所有端一致：

- 绿色（完成）：已发货、已处理、已收、已付款、已收货、已提交、已入库、已出库、已报损、已盘点、有效、够用、已使用（门店邀请）。
- 灰色（结束、无效）：已取消、已关闭、已作废、已拒收、停订、已过期（门店邀请）、无需付款。
- 琥珀色（等待）：待确认、待发货、待处理、未收、部分收、待收货、待填报、待付款、待使用（门店邀请）。

门店端对收款状态的叫法（未付、部分付、已付）颜色同未收、部分收、已收。

状态中文名和颜色都从 `shared` 的状态表里取，页面不写。

## 3. 字体、图标、图片

- 正文：系统字体。
- 标题、金额、空状态：思源宋体（Noto Serif SC）子集，只含数字、¥、常用标点和页面标题、模块名用到的字。`wx.loadFontFace` 在 `app.onLaunch` 里全局加载，加载完成前用系统宋体或系统字体，不阻塞页面。子集由 `scripts/` 从代码里的标题文案自动抽字生成。
- 封面字标 HUAZHONG：Playfair Display 画成 SVG，作为图片放在主包。
- 图标：Lucide 线性图标，1.5px 线宽，按需生成 iconfont，颜色跟随 `color`。TDesign 组件内置的图标能换就换成 Lucide，换不了的调成同样粗细和颜色。
- 品牌封面：管理员在「我的 → 品牌封面」上传一张原图（建议不小于 1600px 宽），后台生成 3 档宽度。各页面按屏幕宽度铺满（`aspectFill`），取景位置固定：
  - 花众首页高 360px、登录页高 300px，取整幅中部。
  - 模块首页高 208px，同一张图放大取局部，每个模块一个固定位置（位置表照原型的封面裁切比例，搭项目时填入 `shared` 的封面配置），底部渐隐到纸色。
  - 管理员没上传时用内置默认封面。
- 产品图：统一 1:1，上传后生成缩略图，列表只加载缩略图，详情加载大图。图片加载前显示 `--hz-tint` 底色占位，加载失败显示同样的占位加一个图片图标。

## 5. 统一状态：加载、网络、异常

所有页面按同一张表处理，页面不自己判断。请求层（`core/request`）把后端错误码转成下面的界面状态，页面只接结果。

### 5.1 加载

| 场景 | 做法 |
|---|---|
| 首次进入页面 | 骨架屏：按页面类型出灰块（列表页 3 张卡片、详情页 标题 + 3 行信息 + 明细、表单页 字段块）。`SKELETON_DELAY_MS` 内回来就不显示骨架，避免闪一下 |
| 下拉刷新 | 微信原生下拉刷新，背景用纸色；刷新时保留旧内容，不出骨架 |
| 列表翻页 | 滚到底自动加载下一页，底部一行「加载中」；全部加载完显示「已显示全部」（次要色 12px），只有一页时不显示 |
| 实时推送后刷新 | 静默重新拉取，不出骨架、不出加载提示；拉完出 `hz-realtime-bar` |
| 提交中 | 按钮文字换成「提交中」并禁用，其他按钮也禁用；超过 `SUBMIT_SPINNER_DELAY_MS` 按钮里加转圈；页面不遮罩 |
| 图片 | 见第 3 节，底色占位 |

### 5.2 网络

| 场景 | 做法 |
|---|---|
| 断网（`wx.onNetworkStatusChange`） | 顶栏下出一条提示「网络已断开，恢复后自动刷新」，页面内容保留可看；恢复后自动刷新当前页并收起提示 |
| 首次加载就失败 | 整页 `hz-state`：「网络不太好，没有加载出来」+ 次按钮「重试」 |
| 刷新、翻页失败 | 保留已有内容，顶部 `hz-error`「刷新失败，请重试」+ 文字按钮「重试」 |
| 提交失败（断网、超时） | 表单内容全部保留，`hz-error`「网络不太好，没有提交成功，请重试」；不自动重发 |
| 超时 | 按提交失败或加载失败处理，文案同上 |
| WebSocket 断开 | 不打扰用户，后台自动重连；重连后整页刷新一次 |

### 5.3 后端错误码

| 错误码 | 界面 |
|---|---|
| `UNAUTHENTICATED` | 回登录页，走手机号快速验证 |
| `ACCOUNT_DISABLED` | 整页 `hz-state`：「账号已停用，请联系花众」，只有「退出登录」 |
| `FORBIDDEN` | 整页 `hz-state`：「没有权限查看这个页面」+「返回」；弹层里出现时在弹层内写 |
| `NOT_FOUND` | 整页 `hz-state`：「没有找到这张单据」+「返回」 |
| `VALIDATION_FAILED` | 按 `fields` 标红对应字段并在字段下写原因，表单顶部 `hz-error` 写第一条原因，滚到第一个出错字段。规则没写专门提示的字段，原因统一写「格式不对，请检查后重试」 |
| `STALE` | 用 `latest` 刷新成最新内容，页面或弹层里写后端给的状态句（例如「订单已变成「待发货」，已刷新成最新内容，请核对后再保存」）；表单里已填的原因保留 |
| `BUSINESS_RULE` | 在页面或弹层里用 `hz-error` 写 `message`，不用 toast |
| `INTERNAL` | `hz-error`「系统出错了，请稍后再试」，下面小字显示请求编号，方便排查 |

拦住操作的错误一律写在页面或弹层里，不用一闪而过的提示。用户重新输入后清掉对应字段的错误。

### 5.4 其他状态

| 状态 | 做法 |
|---|---|
| 空状态 | `hz-state` 空：衬线字一句「暂无 + 对象」，上方 28px 陶土短线；筛选后为空也用同一句 |
| 不可操作（状态不允许） | 按钮只按后端返回的 `actions` 显示；没有可做的操作时，用 `hz-notice` 显示后端给的 `lockedReason`，例如「已付款，不能再退货或改单价」。前端不按状态自己推算（00 章第 1 节） |
| 条件未满足 | 显示禁用按钮。业务条件（例如门店停用时的「确认订单」）来自后端 `actions` 里 `enabled: false` 的项，按钮下方写它的 `disabledReason`；只和本页输入有关的条件（例如还没勾选花材）由前端按输入禁用 |
| 操作成功 | `wx.showToast`，写结果，带图标最多 7 个字（「订单已确认」「已付款」），更长用 `icon: 'none'`；停留 `TOAST_DURATION_MS` |
| 放弃修改 | 改过内容再离开（返回、×、遮罩、右滑、安卓返回键），`hz-confirm`「放弃修改吗？」；改回原值不算修改 |
| 别人改了单（实时） | 查看页：静默刷新 + `hz-realtime-bar`。编辑页：不覆盖输入，出 `hz-realtime-bar`「这张订单刚被修改，点此查看最新内容」，用户点了才刷新；提交时仍有 `STALE` 兜底 |
| 分享链接失效 | 整页 `hz-state`：「邀请已失效」+ 一句原因（已取消、已提交、已过期）+「返回」 |

## 6. 统一格式（`shared/format` + 一个 WXS 工具文件）

| 内容 | 格式 | 例子 |
|---|---|---|
| 金额 | ¥ + 千分位 + 两位小数；后端给分，只在显示时换成元 | ¥1,234.50、¥0.00 |
| 减项金额 | 前面加「−」（全角减号） | −¥136.00 |
| 数量 | 整数 + 空格 + 单位 | 15 束、60 枝 |
| 日期（卡片、列表） | 今年的写 月-日，不是今年的写全 | 09-30、2025-12-28 |
| 日期（详情、表单） | 年-月-日 | 2026-09-30 |
| 时间 | 年-月-日 时:分 | 2026-09-30 08:10 |
| 顶栏日期 | 年.月.日 + 周几 | 2026.09.30 周三 |
| 单号 | 后端给什么显示什么，不拆不改 | SO-260930-001 |
| 状态 | 传状态码，组件取中文名和颜色 | 待发货 |
| 手机号 | 列表里中间四位打码，详情和编辑里完整 | 138****5678 |

业务日期（今天、出货日期、发号）都按 `Asia/Shanghai` 算，不用手机本地时区。

## 7. 文案规则

- 金额名称全站统一，见 03 章第 4 节，不换叫法。
- 按钮写动作：「确认订单」「登记收款」「作废售后」，不写「确定」「提交」这类泛词（弹层里的最终确认可以用「确认取消」「确认作废」）。
- 成功提示写结果，不写规则；报错写原因和怎么办，一句话。
- 空状态「暂无 + 对象」；页面不放规则说明，只放状态提示和需要核对的警告。
- 文案集中放在 `shared/copy`，页面和组件从这里取，方便统一修改。

## 8. 视觉验收

- 组件：在「组件总览」页逐个核对每个组件的所有状态，和冻结原型对照。
- 页面：每个页面按 375、390、430 三个宽度截图，和原型同一页对照；iOS、安卓各一台真机看字体、细线、安全区。
- 状态：每类页面至少过一遍 第 5 节的加载、空、断网、出错、提交中、过期、实时刷新。
- 检查项：只用设计变量（Stylelint）；点击区域不小于 44px；次要文字对比度不低于 4.5:1；页面上没有第二种按钮、卡片、标签样式。
- 发现和原型不一致的，先确认是改原型的设计还是改实现，不在代码里临时调整。
