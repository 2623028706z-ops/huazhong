## 第 3 批 流程接续
1. 单张发货（shipping/pages/ship）成功：弹「已发货」，**不退回列表**，原地刷新成已发货详情，底栏「返回列表 / 送货单」（送货单 = 现有 delivery 页 ?id=）。
2. 批量发货（shipping/pages/list）成功后弹「发货结果」弹层：头行「已发货 n 单，m 单没发出」（全成功只写已发货 n 单）；成功每单一行（客户·门店 / 单号·已发货）右侧「送货单 ›」；失败行写原因、右侧「查看 ›」进该单；底栏「知道了」。从送货单返回**回到结果弹层**。
3. 到货差异告诉采购员：仓库收货时实收少于下单、改了价、或收货后退货 → 这张采购单记为「到货有差异」，进采购员待办（采购模块待办新增一行「到货有差异 n」，key 自定如 poDiffs，点进采购单列表筛好）。采购单详情顶部黄色提示条「到货和下单不一样」+ 逐项差异（花材 实收 x（下单 y）· 单价 a → b · 退货 n）+ 收货人·时间 + 「知道了」按钮；点了后台记「采购已看过」（新字段），从待办消掉；再有新差异（再次改价/退货）重新进待办。**收货后改价、退货维持只归仓库**（不改权限）。
4. 门店底栏「订单」角标 = 有结果（已处理/已关闭等终态）且门店没看过的售后 + 取消申请被同意或拒绝且门店没看过的订单。订单页「订单」「售后」段名带数字；没看过的卡标题前小红点；**门店点开那张详情就消**（后台新记门店已看过，新字段/表）。
5. 门店订单页「售后」段底栏「申请售后」→ 选订单页（复用销售 order-pick 的逻辑，门店版只列本店、售后期限内已发货订单，动作码 applyAfter）→ 门店售后表单（不变）。去掉「要申请售后，打开已发货的订单…」那行文字。订单详情里的「申请售后」保留。
6. 盘点：仓库首页点「盘点」直接弹分类层（默认全选，每类显示 n 种花材），底栏「开始盘点（n 类）」进 stocktake-form；弹层右上「盘点记录 ›」进 stocktakes。仓库首页 4 个入口格不变。
7. 发货单列表从首页进默认「待发货」页签。卡片「产品 20 束」字段改叫「数量」。

## 第 4 批 页面模板和一致性
1. 7 种模板（模块首页、列表、详情、整页表单、作业页、往来汇总、我的），区块顺序见 batch4/p01。**操作只放底栏**（最多 2 个，其余收进「更多」）；卡片里、列表头、信息卡里不放按钮（客户门店页「新建客户 / 修改客户」、花材抬头「修改花材」、往来卡右上「修改」、退款行「作废」等挪底栏或「更多」）。详情页顺序统一：进度条 → 提示条 → 信息卡 → 明细 → 记录。对账单详情、门店售后表单改套公共模板。列表页一律有搜索框（门店订单段补搜索：单号、产品）。
2. 列表卡按岗位排主次（新卡样式见 batch4/p02~p04 的 .rc）：大字 = 认单依据，下面一行小字次要信息（单号降到小字末尾），右侧状态标签 + 金额；零值、空值不显示；约 80px 高。
   - 门店订单：大字出货日期（「出货 09-28 周日」/「出货日期待定」），小字产品摘要 · 单号，右状态 + 金额。排序：待确认、待发货按出货日期近→远在前，已发货按出货日期倒序在后。
   - 发货单：大字客户·门店，小字产品摘要 + 数量，右出货日期（过了标红「已过」）+ 配货 n/m 种。
   - 销售订单：大字客户·门店，小字出货日期 · 单号，右状态 + 金额。
   - 财务客户/供应商往来：大字往来方，小字未结清 n 张 · 对账截止 · 最近收款（有才显示），右侧只放一个数（有未收放未收，否则有多收放多收，都没有不放）；没往来写「还没有往来」。排序：有逾期在前 → 未收金额大到小 → 没欠款。供应商往来补「有逾期」页签；客户、供应商往来加「可开对账单」页签（第 1 批首页待办点进来停在这个页签）。
   - 采购单（采购员）：大字供应商，小字花材摘要 · 下单日期，右金额。采购单（供应商端）：大字下单日期，小字花材摘要 · 单号。
   - 填报邀请（员工）：大字供应商，小字花材摘要 · 邀请日期。填报（供应商）：大字邀请日期，小字花材摘要。
   - 售后（员工）：大字客户·门店，小字原订单 · 提交日期，右售后金额。售后（门店）：大字问题产品，小字提交日期 · 单号。
   - 收付款记录：大字客户/供应商，小字日期 · 方式，右金额。对账单：大字对账期间，右金额。盘点：大字分类，小字盘点日期 · 差异 n 种。
   - 库存、出入库记录等行式列表不动。
3. 组件状态：禁用的主按钮保留主色调淡（opacity 约 .4，白字），不再像次按钮。批量勾选统一一套：「全部」和能批量的那个页签都显示勾选框，只有能操作的单子显示框可勾；没勾时底栏是新建，勾了换成「全选 / 批量 xx（n）」（发货单、销售订单、采购需求统一；新建对账单不变）。**发货单出货日期没到的不能批量勾（照规格 06 H2）**。页签数字统一红底白字小圆、0 不显示；财务往来页签补数字。
4. 表单对齐选 **A**：整页表单一律字段名靠左、值靠右、不带框（现在金额/数量/电话的 120px 小框也去掉，统一靠右），空的显示浅色占位字（「请填写」「选填」）；多行备注同样对齐。弹层保持整条带框靠左。规格 02 章「输入框亮格底 + 细描边」改为「页面行内靠右无框、弹层整条带框」。

## 补充决定（2026-10-06 规格书助手提出后用户定）
- 到货有差异范围：少收、多收、改价、收货后退货、整单拒收、作废已收货采购单，都算。待办只给这张单的采购员（管理员也能看到）。
- 没有仓库权限的采购员在「我的 → 库存查询」也能管理分类 / 新建花材（后台接口对采购开放）。
- 门店已看过：售后看过后又被作废 → 重新算没看过；销售代建的售后有结果也提醒门店。
- 门店订单排序：待确认最前 → 待发货按出货日期近→远 → 已发货按出货日期倒序。
- 采购需求页：全选放列表顶部一行，底栏「邀请供应商 / 新建采购单」。
- 财务往来卡：有逾期显示「逾期」标签；未对账 > 0 时小字写「未对账 ¥x」；没有就不显示。
- 底栏「更多」：底栏最左「更多」文字，点开半屏列出其余操作，不能点的也列出写原因。
- 列表卡小字不写字段名、用「 · 」连接；日期今年写「09-28 周日」，不是今年写完整日期；详情页仍写全字段名和完整日期。
- 卡片里不放按钮的例外：订货页「上一单」条的「再来一单」、弹层里的按钮（邀请订货、解绑微信）保留。
- 搜索框：只补供应商列表（搜名称、联系人）；供应商填报、对账、盘点记录不加。
- 退款行「作废」：点那一行打开这笔退回的弹层，作废放弹层底栏（按「操作只放底栏」）。
